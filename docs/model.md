# 车辆 MPC 模型骨架（讲解参考版）

> 这是一份用于学习的参考稿，不是已经验证过的最终车辆参数。坐标和公式采用常见的自行车运动学模型；参数、权重和约束先给一组能启动仿真的初值，之后要结合你的仿真调整。读懂后，可以在 `understanding` 文档里用自己的话总结。

## 0. 先做三个决定

1. **坐标约定：选 A**——车头沿 `+x`，直行时 `θ_ref = 0`。这样 `x` 向前、`y` 向左，公式和常见示例一致。
2. **角度与转向正方向**：`θ` 从 `+x` 轴开始量，逆时针为正；`δ > 0` 表示前轮向左转。
3. **初始参数**：轴距 `L = 2.5 m`，采样时间 `T = 0.1 s`，预测步数 `N = 20`（即向前看 `2 s`）。`L=2.5 m` 沿用数值例子的设定；`T` 和 `N` 是教学起点，不是已经针对某辆车调好的值。

> 如果用屏幕像素画图，屏幕的 `y` 轴通常向下。那只是显示方向；计算仍按这里的数学坐标约定，必要时在绘图时翻转 `y` 轴。

## 1. 目的

本项目用自行车运动学模型预测车辆运动，并用 MPC 调节加速度 `a` 和前轮转角 `δ`，让车辆跟踪给定的参考轨迹，同时尽量减小位置、航向和速度误差，并遵守车辆输入限制。

这里先用**按时间采样的参考轨迹**作为入门版本：每个时刻都有一个目标位置、航向和速度。它实现简单，适合先跑通 MPC；它和“只关心几何路径、允许快慢不同”的路径跟踪有区别，见第 5 节。

## 2. 变量表

| 符号 | 含义 | 类别 | 单位 |
|---|---|---|---|
| `x, y` | 后轴中心在平面坐标中的位置 | 状态 | m |
| `θ` | 车身朝向相对 `+x` 轴的角度 | 状态 | rad |
| `v` | 车辆沿车头方向的速度 | 状态 | m/s |
| `a` | 纵向加速度，由控制器选择 | 输入 | m/s² |
| `δ` | 前轮转角，由控制器选择 | 输入 | rad |
| `L` | 前后轴之间的距离（轴距） | 参数 | m |
| `T` | 每次更新的时间间隔 | 参数 | s |
| `N` | 预测时域中的离散步数 | 参数 | 步，无量纲 |

- 状态向量 `X = [x, y, θ, v]ᵀ`，共 4 维。
- 输入向量 `u = [a, δ]ᵀ`，共 2 维。
- **状态**描述车辆当前处于什么运动状态；**输入**是控制器现在可以下达、用来改变后续状态的量。这里 `v` 是状态，因为车辆当前速度是运动结果；`a` 是输入，因为控制器可以要求车辆加速或减速。

## 3. 连续时间模型

### 示意图应该标什么

画出后轴中心、车头方向 `θ`、前轮转角 `δ`、轴距 `L`，以及转弯时的圆心。匀速转弯时，后轴中心沿圆弧走，圆心到后轴中心的距离是转弯半径 `R`。

### 公式

```text
ẋ = v cos(θ)
ẏ = v sin(θ)
θ̇ = (v / L) tan(δ)
v̇ = a
```

### 每一行在说什么

- `ẋ = v cos(θ)`：速度 `v` 沿车头方向，把它投影到 `x` 轴上，得到 `x` 的变化速度。
- `ẏ = v sin(θ)`：同一速度投影到 `y` 轴上，得到 `y` 的变化速度。所以直行朝 `+x` 时 `θ=0`，有 `ẋ=v`、`ẏ=0`。
- `θ̇ = (v/L)tan(δ)`：车辆越快或方向盘打得越多，朝向变化越快；轴距越长，同样转角下转向越缓。
- `v̇=a`：加速度是速度对时间的变化率。

当 `δ=0` 时，`tan(δ)=0`，所以 `θ̇=0`：在这个模型里，车头不再转动，车辆沿当前朝向直行。给定相同 `δ` 时，`v` 越大，`θ̇` 的绝对值越大，转得越快。

### 几何关系简推

在无侧滑的自行车模型中，后轴中心的速度沿车身方向，前轮速度沿前轮方向。车辆转弯时，两条速度方向的法线交于同一瞬时圆心。由轴距和转弯半径组成的直角三角形可得 `tan(δ)=L/R`。又因为后轴中心的线速度满足 `θ̇=v/R`，代入便得到 `θ̇=(v/L)tan(δ)`。

## 4. 离散化

控制器每隔 `T` 秒更新一次。先假设一次更新间隔内输入保持不变（零阶保持，ZOH），再用前向 Euler 近似连续模型：用区间开始时的状态斜率，估算走完这一个小时间间隔后的状态。

```text
x[k+1]     = x[k]     + T v[k] cos(θ[k])
y[k+1]     = y[k]     + T v[k] sin(θ[k])
θ[k+1]     = θ[k]     + T (v[k] / L) tan(δ[k])
v[k+1]     = v[k]     + T a[k]
```

**ZOH 和 Euler 是两件不同的事**：ZOH 说的是一个采样间隔内输入怎么处理；Euler 说的是如何近似计算状态从区间起点走到终点。Euler 更新用的是区间起点的 `v[k]` 和 `θ[k]`，不是终点的值。

### 数值例子

取 `T=0.1 s`、`L=2.5 m`、`x=y=θ=0`、`v=2 m/s`、`a=0.5 m/s²`、`δ=0.1 rad`：

```text
x_next     = 0 + 0.1 × 2 × cos(0)                  = 0.2 m
y_next     = 0 + 0.1 × 2 × sin(0)                  = 0 m
θ_next     = 0 + 0.1 × (2/2.5) × tan(0.1)          ≈ 0.00803 rad
v_next     = 2 + 0.1 × 0.5                         = 2.05 m/s
```

若 `T` 取得太大，一步内车头可能已经转过不少角度，但 Euler 仍用起点朝向估计整段位移；加速时它也用起点速度估计整段位移，所以位置预测误差会增大。急转弯或高速时，一步内航向变化通常更大，位置误差也更明显。

## 5. 代价函数

### 入门版本先选轨迹误差

选择**轨迹误差**，即在每个预测时刻对齐一个带时间索引的参考点。它不需要先找路径最近点，适合先完成一个可运行的版本；代价是车辆如果落后，参考点仍按时间继续向前移动。

```text
e[k] = [
  x[k] - x_ref[k],
  y[k] - y_ref[k],
  wrap(θ[k] - θ_ref[k]),
  v[k] - v_ref[k]
]ᵀ
```

`wrap(α)` 把角度差折回 `[-π, π)` 的最短有符号角度范围。例如车头 `+179°`、目标 `−179°`，直接相减是 `358°`，但实际只差 `−2°`；不 wrap 会让控制器误以为要转很大一圈。

### 先用的 MPC 目标

```text
J = Σ[k=0..N−1] { e[k]ᵀ Q e[k]
                  + (u[k] − u_ref[k])ᵀ R (u[k] − u_ref[k]) }
    + e[N]ᵀ P e[N]
```

其中 `u[k]=[a[k], δ[k]]ᵀ`。直线匀速参考的 `u_ref` 通常为零；如果参考轨迹包含曲线或变速，可以用参考曲率 `κ_ref` 和参考速度估计前馈：

```text
δ_ref[k] ≈ atan(L κ_ref[k])
a_ref[k] ≈ (v_ref[k+1] − v_ref[k]) / T
```

这样 `R` 惩罚的是“偏离参考控制的幅度”，而不是一味逼着车辆把转向角压到零。若第一版没有参考曲率，先在直线路径上令 `u_ref=0`，并清楚记录这个简化。

### 权重的可用初值

先用“允许误差尺度”的倒数平方来定权重，便于理解：位置误差按 `0.5 m`、航向误差按 `10° = 0.1745 rad`、速度误差按 `1 m/s` 作为初始尺度；输入变化按 `2 m/s²` 和 `30° = 0.524 rad` 作为尺度。这样可以从以下初值开始：

```text
Q = diag(4, 4, 32.8, 1)
R = diag(0.25, 3.64)
P = 3Q
```

这些数字只是教学起点：`Q` 越大，越重视跟踪误差；`R` 越大，控制动作通常越保守；`P` 越大，越重视预测时域最后一步的误差。`P` 能减少控制器把纠偏一再推迟到预测范围之外的倾向，但单独加大 `P` 并不能保证闭环稳定。

| 项 | 惩罚什么 | 权重变大时通常怎样 | 本稿初值与理由 |
|---|---|---|---|
| `Q` | 预测过程中的位置、航向、速度误差 | 更努力贴近参考 | `diag(4,4,32.8,1)`；用上述误差尺度换算 |
| `R` | 控制量相对参考控制的偏离 | 动作更保守、可能留下更大误差 | `diag(0.25,3.64)`；用加速度与转角尺度换算 |
| `P` | 预测末端的状态误差 | 更重视时域末端状态 | `3Q`，先作为初值 |
| `S`（Phase 3） | 相邻控制量的变化 | 控制更平滑，但反应可能变慢 | 先不加入；之后可加 `ΔuᵀSΔu` |

### 如果要做“只跟路径、不跟时间”

路径误差通常不用绝对 `x、y` 差，而用横向偏差、航向偏差和速度偏差。若参考路径点为 `(x_ref,y_ref)`、切线角为 `θ_ref`，可以定义：

```text
e_lat = −sin(θ_ref)(x − x_ref) + cos(θ_ref)(y − y_ref)
e_ψ   = wrap(θ − θ_ref)
e_v   = v − v_ref
e_path = [e_lat, e_ψ, e_v]ᵀ
```

`e_lat` 是当前位置相对路径切线左侧法向的偏差；它和 `x、y` 两个坐标误差不是一回事。路径版本需要先把车辆或预测状态对应到路径上的参考位置（例如按弧长进度或最近点匹配），所以建议先用上面的轨迹误差跑通，再决定是否切换。

## 6. 约束（Phase 3 再调）

以下是便于开始仿真的**示例范围**，不是针对实车认证过的限制。若仿真模型代表另一辆车，应据此更换数值。

| 约束 | 不等式 | 物理原因 | 示例初值 |
|---|---|---|---|
| 速度范围 | `0 ≤ v[k] ≤ 8` | 限制倒车与最高速度 | `m/s` |
| 加速度范围 | `−2 ≤ a[k] ≤ 2` | 限制制动和加速能力 | `m/s²` |
| 转向角范围 | `−0.524 ≤ δ[k] ≤ 0.524` | 前轮不能无限转向 | `rad`，约 `±30°` |
| 转向角变化率 | `\|δ[k]−δ[k−1]\| ≤ 0.05` | 避免方向盘瞬间跳变 | 每步 `rad`；对应 `0.5 rad/s`、`T=0.1 s` |

硬约束要求解必须落在范围内；代价惩罚只是让超出或偏大的行为变得“更贵”，本身不保证不超限。约束设得太紧、彼此冲突，或当前状态已经在允许范围外时，优化问题可能无解。角度写成弧度参与公式：`30° = π/6 ≈ 0.524 rad`。

## 7. 完整 MPC 流程

1. **读取**：取得车辆当前的 `x、y、θ、v`。
2. **对齐参考**：按当前时间或路径进度，取未来 `N` 步的参考状态与参考控制。
3. **预测与优化**：用离散自行车模型预测未来状态，寻找使 `J` 最小且满足约束的控制序列。
4. **执行**：只发送序列中的第一个控制量 `(a[0], δ[0])`，不一次性执行整段预测，因为真实车辆和模型会有误差，也可能受到扰动。
5. **重算**：过 `T` 秒后重新读取状态，再预测、优化和执行。

这叫**滚动时域控制（Receding Horizon Control）**：每次向前看一段，但只实施眼前一步，再用新状态重新规划。

## 8. 假设与局限

1. 模型假设轮胎没有明显侧滑，所以在高速急转、湿滑路面或极限操控时预测可能不可信。
2. 模型把转向和加速度当成即时生效的输入，没有建模电机、刹车和转向机构的延迟，所以执行器较慢时预测会偏乐观。
3. 模型假设 `x、y、θ、v` 已准确测得，没有传感器噪声；真实测量有噪声时，控制量可能抖动。
4. 前向 Euler 是近似；`T` 大或转向剧烈时误差更明显。
5. `θ̇` 与 `v` 成正比，车停住时本模型不会原地改变航向；它也不描述车辆倒车时所有真实车辆细节。
6. 时间轨迹误差要求车辆按时到达参考点；如果车辆落后，可能会努力追逐已经向前移动的目标。

## 一句话串起来

自行车模型把当前状态和控制输入变成未来状态预测；MPC 在有限预测时域内权衡跟踪误差、控制幅度和约束，再只执行第一步，并利用下一次测量继续重算。


## 仓库实现补充（Codex 整理，2026-11-14）

- Phase 1 双积分器：状态 `[p,v]`、输入 `a`，精确 ZOH 更新为 `p_next=p+T*v+T*T*a/2`、`v_next=v+T*a`；`T=0.1`、`N=20`、目标 `[5,0]`，`Q=diag(1,0.1)`、`R=0.1`、`P=Q`，约束 `abs(v)<=1`、`abs(a)<=0.5`。
- Phase 2 不加输入/速度约束，`S=0`；Phase 3 约束方案使用 `delta_max=0.5236 rad`、每步转角变化上限 `0.05 rad`，其余范围同第 6 节。
- Phase 3 的变化惩罚为 `sum((u[k]-u[k-1])^T S (u[k]-u[k-1]))`，预测首步的上一输入为实际上一时刻执行值；初始值为零。实验使用 `S=diag(0.1,0.5)`，并与 `S=0` 比较。
- 数值角度误差通过 `atan2(sin(e),cos(e))` 实现；在正负 pi 的切口处不光滑，本项目不声称从任意初始朝向均收敛。
- MPC 中转向限幅是优化约束；pure pursuit 的限幅和变化率限制是计算控制指令后实施的。


## 可靠性与扩展实验补充（2026-11-14）

- 优化器始终保留 `abs(delta) <= pi/2 - 0.001 rad` 的数值定义域限制。“无约束”实验仅关闭物理输入/速度限制，不允许使用 tan 的其它分支。
- 求解失败、非有限结果或约束残差超出 1e-6 时，闭环实验立即停止并报告步数与状态。没有复用上一输入的降级控制；这也不等于实车紧急处置策略。
- 有限路径上的匀速参考若超出路径长度会报错。路径末端停车尚未实现。
- 实验 06 的真实车辆轴距失配、固定输入延迟与观测噪声只是单独注入的敏感性条件，不改变标称控制器的预测方程。
- 实验 07 固定物理预测时间 2 s，令 N=2/T；转角变化上限为 0.5*T rad。相对 T=0.1 s，Q、R 乘以 T/0.1，S 乘以 0.1/T，P 保持不变，以比较近似一致的物理代价尺度。
